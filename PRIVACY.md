# Privacy Policy

Effective: 2026-10-21

MozahhemGir is designed to work entirely on the user's Android device.

## Data collection

MozahhemGir does not collect, transmit, sell, rent, or share personal data. It has no Internet permission and contains no analytics, advertising, crash-reporting, or telemetry SDK.

## Data processed locally

To make a screening decision, Android provides the call-screening service with information required by the platform. The app normalizes the incoming caller number in memory and compares it with locally stored prefixes. The app does not upload or synchronize caller numbers.

The following settings are stored locally using Android SharedPreferences:
- whether filtering is enabled;
- the user's prefix list;
- a numeric count of calls blocked by the app.

Android backup is disabled for the application.

## Contacts and call log

The app does not request Contacts, Call Log, Phone State, SMS, Location, Microphone, or Internet permissions.

## Rule catalog

The default rule catalog is bundled with the application at build time. The app does not download or update rules remotely.

## Changes

Material privacy changes should be documented in the repository and release notes before distribution.
